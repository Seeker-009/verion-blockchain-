# VERION TOKENOMICS
## Draft Version 0.1

### 1. Cryptocurrency Identity

- Name: VERION
- Ticker: VRN (provisional)
- Blockchain: Independent Layer-1
- Native Coin: VRN
- Status: Proposed

### 2. Purpose of VRN

VRN is intended to serve as the native cryptocurrency of the VERION network.

Potential uses:
- Paying transaction fees.
- Staking to secure the network.
- Validator rewards.
- Transferring value.
- Participating in network governance.

### 3. Total Supply

- Maximum Supply: Undecided.
- Initial Supply: Undecided.
- Circulating Supply: Undecided.
- Smallest Denomination: Undecided.

### 4. Distribution Categories

Potential allocation categories:
- Community and ecosystem.
- Validator rewards.
- Development and maintenance.
- Network treasury.
- Initial distribution.

No percentages have been approved.

### 5. Transaction Fees

VRN will be the proposed currency for network transaction fees.

The fee system must balance affordability, security and sustainability.

### 6. Staking

If Proof of Stake is selected, VRN may be staked to support network validators.

Reward rates and staking rules remain undecided.

### 7. Governance

A future governance system may allow eligible participants to vote on network proposals.

### 8. Current Status

Tokenomics remain under development.

No VRN coins have been issued or launched.

No investment returns are promised.
