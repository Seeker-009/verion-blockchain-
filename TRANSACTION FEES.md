# VERION TRANSACTION FEE SYSTEM
## Draft Version 0.1

### 1. Introduction

VERION will use a transaction fee system to process transactions and help protect the network against spam.

The proposed native coin used for fees is VRN.

### 2. Purpose of Transaction Fees

Transaction fees may serve to:

- Pay for transaction processing.
- Discourage spam and malicious activity.
- Support network validators.
- Help maintain network security.

### 3. Fee Structure

The final fee structure has not been selected.

Potential models include:

- Fixed transaction fees.
- Dynamic fees based on network demand.
- Minimum network fees.

The system should aim to keep ordinary transactions affordable.

### 4. Fee Distribution

Possible distribution methods:

- Validator rewards.
- Network treasury.
- Protocol-defined fee burning.

No percentages have been approved.

### 5. Fee Security

The network must prevent:

- Fake transactions.
- Fee manipulation.
- Spam attacks.
- Unauthorized fee changes.

### 6. Future Improvements

The fee system may be updated through an approved network governance process.

### 7. Current Status

Transaction fee amounts, distribution percentages and fee-burning rules remain undecided.

No live VERION transaction fee system currently exists.
