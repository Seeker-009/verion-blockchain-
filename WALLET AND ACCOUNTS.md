# VERION WALLET AND ACCOUNTS
## Draft Version 0.1

### 1. Introduction

VERION will require a wallet system that allows users to interact with its independent blockchain.

The wallet will support the native cryptocurrency, VRN.

### 2. Wallet Functions

The proposed wallet should allow users to:

- Create a blockchain account.
- Receive VRN.
- Send VRN.
- View account balances.
- Check transaction history.
- Pay network transaction fees.
- View transaction confirmations.

### 3. Account Addresses

Each account will have a unique blockchain address.

Users will share their public address when receiving VRN.

### 4. Private Keys

Private keys authorize transactions.

Security requirements:

- Private keys must remain confidential.
- Users must control their own private keys.
- Recovery phrases must never be shared.
- Wallet software must protect sensitive information.
- Private keys must never be stored in plain text.

### 5. Wallet Security

VERION will investigate:

- Secure key generation.
- Recovery phrase protection.
- Transaction signing.
- Account recovery options.
- Protection against unauthorized access.

### 6. Wallet Compatibility

The wallet should eventually support:

- iOS devices.
- Android devices.
- Desktop computers.
- Web access, if security requirements permit.

### 7. Transaction History

Users should be able to view:

- Transaction identification.
- Sender address.
- Receiver address.
- VRN amount.
- Network fee.
- Transaction status.
- Block confirmation information.

### 8. Current Status

Wallet design remains at the planning stage.

No VERION wallet or account system has been developed or launched.
